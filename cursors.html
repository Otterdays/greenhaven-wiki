Cursors

The window cursor in Greenhaven is not the operating system's - it is a custom sprite drawn by the client, so it looks the same on every platform and matches the world's art. Three ship today.

The three shipped

CursorFeel
Classic ArrowA plain, high-contrast pointer. The safe default on any theme pack.
Dot PointerA minimal dot with a soft ring. Reads small on a busy field.
Twig LadybugA little twig with a red-and-black ladybug sitting on it. The most Greenhaven of the three.

A preview of the Twig Ladybug ships on the Gallery so you can see the art at real size.

How a cursor is made

Each cursor is a small JSON model in the same shape as a character sheet: a size, a hotspot, and a table of pixel runs. A dedicated Cursor Maker tool sits beside the map painter and the model maker - it opens the JSON, shows a live preview, and writes the file back. Nothing in the game reads a raw PNG at runtime; the client synthesises the cursor texture from the JSON so it stays crisp at any cursor scale.

Picking and sizing

Cursor choice and cursor size both live in Settings > Controls. The size is a plain scale - Normal keeps the authored pixel size - and applies to the custom cursor the game forces on, so a large cursor stays large on every window resolution.

Why a custom cursor at all

Three reasons: consistency across Windows, macOS, Linux and the web; a hotspot that matches the art (a ladybug's head, not a stock arrow's tip); and no white-on-white moment when a player on a dark theme moves over a light panel. Once the client owns the cursor, every theme pack repaints cleanly.

Adding more

A new cursor is one file in assets/cursors/, one row in the client's cursor registry, and one entry in the Cursor Maker's palette. Ids never change, so a saved preference keeps working across versions.
