Chat and Commands

Chat is one box with three shapes: a glance strip that fades, an expanded review you can scroll, and a compose line you type into. Three commands live in the same box: /time, /w and /clear.

The three chat shapes

  • The glance box sits in the corner while you play. Each new line shows for about ten seconds, then fades on its own.
  • The expanded review is the scrollable log. Open it with a click on the Chat bubble or on any visible glance line.
  • The compose line opens with Enter. Latest messages sit above the "> _" line so you can read what you are replying to.

While the expanded review is open the glance box steps aside, and clicking the Chat bubble drops any half-typed draft so you never type into an invisible box.

Typing rules

  • Every line caps at 160 characters - the same cap for a chat and for a whisper. A whisper is private, not a licence to send more.
  • Control characters are stripped as you type. Backspace deletes, Enter sends, Escape cancels.
  • A stray click on the box while you type no longer throws your draft away.
  • The Windows IME is enabled while you compose so CJK input still commits, same as the menu name field.

Guild tags

Every chat and whisper line is prefixed with the sender's guild tag in brackets: [LNTN] Ranger: hello. A guildless player has no bracket. See Guilds.

Commands

CommandWhat it does
/timeAsks the world for its clock. The reply is a single line printed in your chat: the world's UTC time. Anyone may use it.
/w <name> <text>Whisper one line to a named player. The rest of the world does not see it. Both sides get the guild tag on the line. Anyone may use it.
/clearEmpties your own chat log. Client-side only - nobody else notices, and the world does not hear you.
/friend <name>Adds a character standing in this world to your friend list. See Friends.
/unfriend <name>Removes a character on your friend list, offline too. See Friends.

Admin commands

Accounts flagged as admin get /give <player> <item> [amount], which hands an item, a stack of coins or a cape to any named character, online or offline. Amounts run 1 to 10,000 per call. See the Coins and Capes pages for the wallets that accept a gift.

Saved or not

Chat history is not saved - it lives in your session only. Your guild, friend list and character names are saved with your account and character.
