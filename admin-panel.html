The Admin Panel

Every world runs with a companion panel: a small browser page an operator uses to search characters, hand out or take back items, capes, pets, coins and crystals, moderate players, and read the audit log. Same data the world sees, no database query required.

Search and inspect

A search bar finds any character by name - online or not. Picking a name opens the inspector drawer. The drawer shows:

  • Status chips (online, admin, guilded).
  • Every skill tile with level, XP into the level, and total XP. Wallets with quick +100, +1k and clear buttons.
  • Twenty equipment slots and what is worn in each, taken off or swapped live.
  • Owned cape swatches with a Worn marker; click one to wear it or take it.
  • Pet cards, one per owned pet: level bar, held items, and Give / Take away buttons.
  • Inventory rows with +1, -1 and all quick actions.

Give and take

The Give-or-take box is one control. Pick a target with a filterable picker grouped as Currency / Items - family / Capes / Pets, choose 1 / 10 / 100 / 1000 as a quick amount, and press Give or Take. The button behind it is the same admin action the world's in-game /give command reaches, so nothing the panel can do is hidden from a player-side admin.

  • Give a coin or crystal stack, an item, a cape, or a pet.
  • Take the same back. A taken cape comes off; a taken pet goes home and its pack returns to the bag. Wallets never dip below zero.
  • Every gift is audited - who gave what to whom, and how much.

Admin flags

An account is admin only when a flag on its row says so. The panel's Make admin toggle flips that flag on any character from the Inspect view. The world re-reads the flag on every admin command, so a revocation takes effect the next time the account talks, not the next time they log in.

Moderation

From the same inspector an operator can kick a player from the world, teleport them to another position, or ban the account. Bans reach the character row and the account row, so a banned account cannot just log in on another character.

Recent admin actions

The panel lists the last set of give / take / grant / revoke / kick / ban actions with a timestamp and the reason, so a second operator can see what has changed recently without opening a log file.

Relationship to in-game commands

An admin in the world itself can type /give <player> <item> [amount] for the same effect, or /take to reverse it. The panel adds a picker for the item and a wallet tile for the coins, but the underlying call is one endpoint. Nothing the panel can do is beyond what an in-game admin can do by typing.

Read-only surfaces

Apart from the inspector, the panel shows a live player table (name, total level, ping, coins, worn gear), a world-status card (which map is loaded, how many players are walking, current world time), and a services card (which worlds the same host runs). None of those are admin-only - the panel is a browser page an operator uses, not a public site.
