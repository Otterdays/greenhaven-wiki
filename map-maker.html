The Map Painter

Every map you can walk in Greenhaven was made in the map painter. It is one tool with twelve modes, a palette of 120 tiles, and a set of per-cell sidecars that let a tile say something different on every cell.

The twelve tools

KeyToolWhat it does
HHandDrag the view, click a cell to inspect, press R to swap a bench or a ramp's rise direction.
BBrushPaint the selected tile wherever the cursor goes. A click-and-drag paints a run.
FFillFlood a region with the selected tile, matching neighbours only.
RRectDrag a rectangle and paint the inside in one pass.
IEyedropperPick a cell and the palette jumps to the tile you clicked.
SSpawnSet where a fresh wanderer lands. One cell per map.
DRespawnSet where a wanderer returns after death. Falls back to Spawn when unset.
NNPCDrop a character from the registry: the jester, a merchant, a wild boar, a wyvern, the Barrow King.
ERaiseLift or lower a cell's height (0 to MAX_HEIGHT, which is 3). Press E again to leave raise mode.
TResource nodeTune one cell's tree, rock, sand, clay or fishing-spot node: level, XP, chance, batch, harvest seconds, respawn seconds, or turn it into pure scenery.
AScatterSprinkle flowers, reeds, cattails or ground clutter in a natural-looking pattern over a painted region.
ZStampDrop a pre-authored stamp - a whole tree cluster, a cottage, a stone ring - in one click. The ghost shows the exact art that will land.

Any single-press tool toggles back to Hand when its key is pressed a second time.

The palette

Every tile the game can place lives in a grouped sidebar: Grass and path, Water, Wood, Cobblestone build, Wood floors, Crafted grounds, Flowers, Trees, Rocks, Fences and hedges, Camp and market props, Festive props, and a Home and Green pack. The palette is the same order the shared tile registry uses, so a wiki page and the painter read the same row.

The resource node panel

Every harvestable tile - tree, rock, sand, clay, fishing spot - carries a "family tile plus a per-cell override" pair. The Resource node tool (key T) opens a panel that shows the tile's defaults and lets you override any subset. A field you do not touch stays at the family default, so an author tunes the one number they care about and the rest of the file does not churn. Turn a node off entirely with a checkbox to make it pure scenery - the game then answers "This node is turned off."

Signs, chests and campfires

The painter's Hand tool also edits the three sidecar tiles. Click a signpost and a text panel opens (up to 120 ASCII characters, newlines allowed). Click a chest and a single "usable" toggle appears. Click a campfire and the size picker cycles. Full rules live on Signs, Chests and Campfires.

How a painted map becomes the world's map

The painter writes the same JSON a world reads at boot: tiles, height map, spawn, respawn, characters, nodes, signs, chests and campfire sizes. The tool has one export path and one import path so a file the painter saves is byte-for-byte the file the world loads. There is no separate "publish" step - a map that paints is a map that ships.
