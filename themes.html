Theme Packs

Fifty-nine colour packs sit behind the theme picker on every developer tool, the launch panel, the wiki and the public porch site. The picker is the same control everywhere - one shared file, one storage key, one cross-tab sync.

How the picker works

  • Auto follows your OS dark / light setting.
  • Filter narrows the panel by name. It re-seats roving keyboard focus so the active option stays tabbable, and announces how many packs are visible.
  • Type-to-jump finds the first pack whose label starts with what you type.
  • Cross-tab sync. Pick a pack in the wiki and the map painter, the launch panel and the model maker all switch on the same tick.

The base packs

Eleven packs sit outside any game series - the everyday palette every tool defaults into.

  • Meadow (default) and Day - the game's own green and parchment pair.
  • Dusk - warm amber on deep brown.
  • Dock, Tide, Mist, Cloud, Reed - five cool waterside looks.
  • Birch, Ember, Stone - bark, fire and grey.

Game packs

The other forty-eight are grouped by the game or world that inspired them. Every one is a full colour set: background, panel, ink, accent, focus, line - not just a swap of the accent. The panel groups them so a section only disappears when every pack inside it is filtered out.

The contrast gate

Every theme pack runs through an automated contrast test on the pairs the tools actually paint: the accent ink on the accent fill, ink on background, ink on panel, and the strong ink on the active tile. The test measures the tightest ratio in the shipped stylesheets and refuses a pack that falls under WCAG AA. A contrast report mode prints the tightest pairs across all fifty-nine packs, always green, so a designer can see where a pair is close without failing the build.

How a pack is defined

One html[data-theme="<id>"] block in the shared theme sheet, and one matching row in the picker's THEMES array. Both files live in the same folder so the id and the colours cannot drift. A new pack appends - never renumber, because a saved theme is stored by id.

Where you can pick a theme

The theme picker shows on every tool page, the launch panel, the map painter, the atlas, the model maker, the cursor maker, the music maker and every wiki page (including this one). The public porch site does not carry a picker - it always ships on Meadow.

Related

The picker control lives beside Settings in feel but is stored per browser, not per install. Every pack repaints the wiki, so a screenshot on the Gallery reflects whichever pack you have active.
