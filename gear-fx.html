Gear Effects

A piece of gear can glow, leave a coloured swing trail, throw sparks or dust when it hits, or pop on impact. Every one of those effects is authored as data in the Gear Forge and shipped as one shared file the client reloads live - no restart between "add glow" and "see glow in game."

The five effect kinds

  • Glow. The piece carries a soft colour aura on the sprite itself. A glowing sword is obvious at a glance; a glowing cape is obvious from behind.
  • Swing trail. When the piece swings, the arc it paints has the piece's colour. A bronze axe throws a warm brown streak; a candy cane sword throws a red-white one.
  • Hit pop. The impact frame of a landed swing carries a small pop - a brief burst at the point the strike connected.
  • Hit sparks. Little motes fly off on impact. A blunt weapon throws dust, an axe throws bark chips, a blade throws sparks, a magic weapon throws glowing points.
  • Dust. A soft ground puff - the shape a digging tool makes on impact, or a mace on stone.

Where the file lives

Every effect a piece carries is one entry in a shared assets/gear-fx.json. The client reads the file once at boot and again whenever it changes on disk - the same live-reload path that repaints gear overlays, so an author saves in the Gear Forge and the running game picks the effect up within a second. The file has a version field and one row per item id; the Gear Forge writes both.

The Gear Forge's Effects panel

Inside the Gear Forge, an Effects panel is where a designer picks the kinds and colours for one piece. Every choice is a colour swatch, a slider, or a checkbox - no typing JSON. The panel shows the current effect for the item you have selected, and the same Ghost of saved overlay the rest of the Forge uses fades out the last saved look so a change is obvious. The Before / after dialog shows the previous render and the new one next to each other.

Per-frame touch-ups

Some effects want a hand tweak on one frame of the swing. A Touch up this frame button opens the small overlay for the exact pose the preview is on, and the Forge checks on save that no stale touch-up is left behind on a frame the item no longer has. The touch-up rides the body's frame index, so the swing animation is what carries the effect - not a separate timeline.

Glowing gear in the client

The world snapshot for a wandering character is a name, a position, and a worn-gear list. Every viewer's client reads the same effects file, so a piece that glows on the wearer glows on every remote viewer too. Nothing about the effect is on the wire - only the item id is, and the effect comes from a shared file the same way an icon does.

Weapon icon turns with the arm

The weapon icon in the swing clip and the held overlay are on the same frame index. When the arm lifts, the weapon lifts with it. When the arm points behind the body - the far side of a swing - the held weapon draws behind the character sprite too, so a sword never floats in front of a body that is turned away.

Engraved and glowing trims

The Gear Forge's trims now include an engraved (a small pattern on the head of a weapon) and a glowing (a rim light on the head or the haunches of an armour piece) variant. Both are the same parts library, snapped in the same synthesiser - just with an effect riding the resulting item.
