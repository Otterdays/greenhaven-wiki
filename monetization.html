Monetization and the Crystal Store

Greenhaven is Early Development and free to play. There is a store behind the Pause menu - it is reachable today, but DEBUG is on, so nothing costs real money yet. This page is the honest shape of the plan.

Two wallets

  • Coins are earned in the world (mining, fishing, trading, admin gifts). See Coins. A coin never leaves the world for a store window.
  • Crystals are the premium wallet. They are only reachable from the store, and they only pay for cosmetics.

Every cape either takes coins (one - the Emerald at 250) or takes crystals. Nothing else in the game does.

What DEBUG means

Two flags run the store. Enabled makes the store reachable and premium capes buyable. DEBUG makes every crystal action cost nothing: a top-up grants crystals with no charge, every price tag on a crystal product reads "DEBUG" instead of a number, and the world writes a loud DEBUG line so an operator cannot mistake a debug build for a live one.

DEBUG is on today. Both flags are true. That is deliberate - the whole buy / wear loop needs to be playable and testable in game before a payment provider is connected, and a debug build must never be pointed at real players expecting revenue.

Turning DEBUG off is not "just a flag". Before any real money is charged, three things must exist:

  1. A verified payment-provider webhook that replaces the DEBUG grant.
  2. Legal cover: terms, refunds, regional rules.
  3. Anti-fraud: chargebacks, stolen cards, refunds clawing crystals back.

The top-up seam

The client sends a "top up" message naming a pack. Today the world treats that as a free grant and logs a DEBUG line. That handler is the seam: a payment provider takes the same call and returns a webhook, and the world only grants crystals after the provider confirms a real charge. The client's message and the world's answer are already shaped for that swap.

What this store will not do

  • No pay-to-win. Crystals buy cosmetics. No XP, no gear advantage, no skill shortcut.
  • No locked gameplay. Every skill, mob and area is reachable without spending.
  • No real-money trading. Crystals are not a currency a player can hand to another player.
  • No loot boxes. Every purchase is a named, visible item at a named cost.
  • No shop-wall on a new player. One cape is always earnable in game with coins, so a fresh wanderer can own something from the store without touching a real wallet.

What DEBUG does not mean

DEBUG does not zero the shop's own costs. A cape still deducts its coin or crystal price from your wallet on purchase. "Free" means "you got the crystals for free from the debug grant", not "the cape is free". The catalog's prices are real prices; only the top-up is fake money today.

Where the code lives

The two flags, the wallet fields, the cape rows, and the crystal-pack rows all live in the shared crate. The world reads them to validate every sale; the client reads them to paint every price. One source, no drift.
