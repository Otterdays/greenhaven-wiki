Crash Codes

Greenhaven is a windowed build with no console behind it, so a startup failure used to close the game without a word. Every way the client can now die shows a short GH-xxx code, one fix to try, and a full report file to send back.

How a crash reads

A crash opens a small Windows message box with:

  • A one-line title ("Greenhaven closed: No usable graphics driver (GH-101)").
  • The one fix to try first.
  • The error code, the game version, and the OS / CPU family.
  • The first line of the underlying error, trimmed to 300 characters so a leaked path or a token cannot be shown whole.
  • Where the full report was saved.

The whole message is copyable with Ctrl+C. A player can read the code out over voice chat and a developer knows what to look at.

The 1xx-9xx shape

Codes are grouped by hundred so a player can tell the shape from the number alone:

  • 1xx - graphics
  • 2xx - files and folder permissions
  • 3xx - memory
  • 4xx - audio
  • 5xx - network
  • 9xx - native faults (a crash below Rust, usually inside a driver) and a fallback for anything unexpected

Codes are stable strings, never renumbered. A new cause adds a row; a retired cause keeps its code so an older report file still reads.

How a cause is picked

A panic message is classified by a small ordered table of keywords: "gpu", "vulkan", "wgpu" and friends mean graphics; "out of memory" means memory; "access is denied" or "read-only" means folder access; "no such file" means files; "cpal", "rodio" and "audio" mean sound; "rustls", "tls" and "tokio" mean network. Order matters - a message that names both a file and the GPU is still a GPU problem. Nothing that is not on the list matches, so an unknown panic lands on GH-999 and the report is what the developer reads.

A native Windows exception (an access violation, a bad instruction, a stack overflow) is caught below Rust and mapped to a GH-90x code. A driver crash on one machine looks like the same code as one on another.

The report file

The full panic message, the version, the OS, and a backtrace are written next to the game as greenhaven-panic.txt. That file is what to attach to a bug report. It is a text file with no formatting, so it survives email and pastes into an issue cleanly.
